# Code of Conduct

## Our standards

We want AgentSafeFS to be a constructive, technically rigorous, and welcoming open-source project. Participants are expected to communicate respectfully, focus criticism on ideas and code, assume good faith where reasonable, and avoid harassment, threats, discrimination, or personal attacks.

Examples of positive participation include:

- giving specific, reproducible technical feedback,
- respecting different levels of experience,
- acknowledging mistakes and correcting them,
- keeping security reports private until coordinated disclosure is appropriate,
- helping discussions stay relevant to the project.

Unacceptable behavior includes harassment, discriminatory or degrading language, deliberate intimidation, publication of another person's private information, sustained disruption, and knowingly exposing an unpatched vulnerability through a public issue when a private reporting channel is available.

## Enforcement

Project maintainers may edit or remove contributions, comments, issues, discussions, or other participation that violates these standards, and may temporarily or permanently restrict participation when necessary.

For conduct concerns, contact the repository maintainer privately through the GitHub account associated with this repository. Security vulnerabilities should use GitHub private vulnerability reporting instead of the conduct channel.

## Scope

This code of conduct applies in project spaces and when an individual is officially representing the project in public spaces.
